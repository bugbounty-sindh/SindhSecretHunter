A powerful GitHub Secret Finder made for Bug Bounty Hunters from **Mehar, Sindh, Pakistan**. Find API keys, tokens, passwords exposed in repositories.

> Built with ❤️ from Sehwan Sharif, Sindh - for the World's Security

### 🚀 Features
- ✅ Finds AWS Keys, Google API Keys, Slack Tokens
- ✅ Fast scanning with Python
- ✅ Made for Termux & Kali Linux
- ✅ Lightweight - No heavy dependencies
